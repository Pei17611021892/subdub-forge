# StoryCut · StoryCut Studio v0.2.2

StoryCut Studio 是独立的 AI 解说剪辑工具，用于把较长的中文原片整理成适合 YouTube Shorts 等平台发布的精简英文解说视频。

当前版本已经完成“理解原片 → 组织故事 → 匹配镜头 → 预览导出”的完整工作流。内部目录名继续保留为 `storycut_v2`，用于兼容既有项目路径；仓库对外只维护 StoryCut 一个应用。

v0.2.0 完成单应用整合：真实配音可在安全范围内整体变速并同步修正 SRT，缺少同步字幕时可主动使用 Faster-Whisper 识别英文配音；字幕支持文字/描边颜色、阴影、斜体、字间距和动画，并持久化 FFmpeg 命令与滤镜诊断文件，同时加入完全本地的成片质量检查。

v0.2.1 会主动读取环境变量或 Windows 系统代理。Clash 只开启系统代理、不开 TUN 时，Python 版本检查、ZIP 下载和后台 Git 更新都会使用该代理；Raw 版本地址失败时自动改用 GitHub 官方 API，仓库 ZIP 主地址失败时自动改用 `codeload.github.com`。

v0.2.2 清理了已经退役的旧版一比一翻译工具及其兼容残留，并增强关键帧理解：原有视觉请求会同时提取清晰可见的画面文字、图表、流程图、表格与公式；只有遇到重要但不确定的技术画面时，才从原视频额外抽取高清帧复查，默认每段视频最多 6 个，不会逐帧调用 API。第 2 步新增默认关闭的科普事实审查，可区分原片证据不足、常识事实、数字单位、因果关系和术语风险；单条安全建议可一键应用，应用后会要求重新审查。最近项目恢复增加加载状态，并把英文配音时长读取移到后台、缓存到项目，避免 FFprobe 阻塞首页。成片检查也改为后台运行，并使用绿、蓝、黄、红状态卡片显示通过、说明、提醒和必须处理项。

从 v0.1.1 起，“理解原片”会提前检查根目录 `.env` 中的 AI 配置；用户也可明确选择仅执行本地分析。组织故事缺少 API 或请求失败时会显示可见错误。首页提供 StoryCut 独立更新入口。

v0.1.2 将缺少 API 时的次要选项明确为“仅做本地预处理”，用于提前完成语音转写、场景切分和关键帧提取等耗时任务；默认引导用户在应用内快速设置 API Key 和可选接口地址，保存后立即继续原操作。同时修复版本更新弹窗的 QML 高度循环警告。

v0.1.3 优化了四步流程首页和故事生成质量，统一步骤卡片与完成状态，改进 GPT-SoVITS 标点断句和 SRT 导出，并增加带确认删除的“最近项目”弹窗。

v0.1.4 增加启动时静默更新检查和可更新标识，并提供基于 `pythonw.exe` 的无 CMD 启动入口。

v0.1.5 默认在缺少 Faster-Whisper 模型时自动下载，界面会单独显示模型文件下载进度；下载完成后自动继续原片理解，无需重新点击。同时限制超长视频名称的显示区域，避免撑开首页布局。

v0.1.6 在首页增加常驻 API 设置入口，可直接查看配置状态并管理共享 `.env` 中的 URL 与 Key；保存时校验并规范化接口根地址，同时为视觉描述和故事生成的 405 路由错误提供针对性说明。

v0.1.7 将应用内更新升级为仓库级同步：点击更新后直接获取 GitHub `main` 分支最新文件，并按清单同步应用和根目录启动器。项目、用户配置、`.env`、模型、输出和导出目录均受保护。

v0.1.8 改为混合更新：Git 克隆用户优先在后台执行 `git pull --ff-only origin main`；检测不到 Git、不在 `main`、受跟踪程序文件有本地修改或 pull 失败时，自动回退到 v0.1.7 的 ZIP 清单更新。程序不会调用 `git clean`、`reset --hard` 或其他用户数据清理命令。

首页顶部的“最近项目”会弹出可滚动列表，可直接继续已有项目；列表外的项目仍可手动选择其 `project.json` 打开。删除项目需要二次确认，会清理该项目目录内的分析结果、配音、预览、导出等文件，但不会删除目录外的原始视频。

点击最近项目“继续”后会立即显示加载状态。配音实际时长会缓存到项目；旧项目首次缺少缓存时改由后台调用 ffprobe，页面先完成恢复，时长读取完成后自动更新。

新项目默认按创建日期命名，例如 `v2-0817`；当天重名时依次使用 `v2-0817-1`、`v2-0817-2`。首页顶部可直接修改当前项目名，项目目录、最近项目显示和之后的导出文件前缀会同步使用新名称。

## 初版功能

### 1. 理解原片

- 使用 FFmpeg/ffprobe 读取视频信息并生成封面。
- “语音与画面”保留原流程：使用本地 Faster-Whisper 转写中文语音，再以关键画面补充上下文。
- “纯画面叙事”跳过 Whisper，除场景关键帧外按时间间隔抽取连续画面，详细分析人物动作、姿态、工具交互、环境、障碍、可见变化和衔接线索。
- 纯画面模式把所选秒数视为期望时长：长片在强行压缩会破坏故事时允许适当延长，但预计旁白和最终导入配音都必须低于 179 秒，给 Shorts 三分钟限制保留安全余量。
- 本地缺少所选模型时默认自动下载到共享 `models/faster-whisper/`，显示独立下载进度并在完成后自动继续。
- 检测场景、抽取关键帧并整理事件列表。
- 可选调用 OpenAI 兼容视觉接口描述关键帧。
- 同一次视觉请求会识别清晰可见的画面文字、图表趋势、图示关系、表格和公式，并把它们作为后续故事与镜头匹配的证据；看不清的内容不会猜测。
- 重要但不确定的技术画面可自动抽取高清原帧复查，默认最多 6 个；没有需要复查的画面时不会增加 API 请求。可在 `vision` 配置中调整或关闭。
- 后台显示分析进度、预计总用时和动态剩余时间。

### 2. 组织故事

- “语音与画面”继续调用 OpenAI 兼容接口生成精简英文解说，保留高信息密度的母语科普 YouTube 写法。
- “纯画面叙事”使用两阶段故事工作流：故事规划模型先通读全片事件，提取目标、阻碍、尝试、转折、结果和余味；最终故事编辑再依据完整证据时间线重写沉浸式第三人称英文解说。
- 最终编辑不会只做表面润色，可以重新选择重点、调整故事阶段、删除读屏式句子并重写潜台词；同时禁止凭空创造时间、天气、声音、气味、失败次数、身份、经历和画外结果。
- 纯画面故事必须覆盖原片开头、中段和结尾；预计旁白达到三分钟、故事明显过短或结构不完整时会触发整篇重编。
- 全片规划单独保存为项目 `script/story_plan.json`，最终解说继续保存为 `script/story.json`。
- 不再强制每个故事使用戏剧化问题或冲突开头，允许自然的长短句节奏；最终再由程序按 GPT-SoVITS 标点拆分。
- 支持 60、90、120、180 秒期望时长，最终硬上限统一为 179 秒。
- 英文文案可在界面内编辑并自动保存。
- 可选运行一次 AI 科普事实审查，核对原片证据、一般事实、数字单位、因果和术语；默认关闭“生成后自动审查”，避免无意增加 API 调用，也可随时手动检查当前文案。
- 审查结果保存为项目 `script/fact_review.json`，按高风险、需确认、精度建议显示对应解说句和最小修改建议；一条建议只对应一句解说时可点击“应用建议”，其他情况仍由用户手动判断。应用建议或编辑解说后，旧报告都会自动标记为需要重查。该功能不联网检索权威来源，也不阻断后续步骤。
- 可导出 GPT-SoVITS 使用的英文参考 SRT。
- 参考 SRT 按英文逗号、句号、问号、感叹号、分号和冒号拆句，兼容标点后没有空格的文本，并保护小数和数字分隔符。
- 旁白预计时长同时参考英文单词数、音节数与标点停顿，避免把短语和长句一律处理成约一两秒；打开旧项目时会在本地自动升级旧时间估算，无需重新调用故事 API；导入同步 SRT 后始终以真实配音时间为准。

### 3. 匹配镜头

- 默认根据事件绑定、字幕、视觉描述、时间顺序和重复使用情况，从全部场景事件中自动挑选镜头。
- 每句解说提供多个候选镜头。
- 正常流程无需逐句选择；候选替换和 0.5 秒入点/出点调整收进可选的“高级调整”。
- 镜头不足时可自动组合多个场景。
- 时间线保存到项目目录，关闭后可继续。

### 4. 预览导出

- 导入 GPT-SoVITS 生成的英文音频和同步 SRT。
- 没有 GPT-SoVITS 同步 SRT 时，可主动使用共享 Faster-Whisper 模型重新识别英文配音；该方式默认不自动运行，CPU 环境可能较慢，断句也可能与原始文案不同。
- 真实配音超过 179 秒时，可在 1.00x～1.25x 安全范围内一键计算最小适配倍率；音频与同步 SRT 同步变速并自动重算镜头时间线。原始导入文件单独保留，可随时恢复原速；最高倍率仍无法适配时会要求删减或重写文案。
- “成片检查”会在后台检查原视频是否变化、故事/镜头文件是否齐全、配音与粗剪是否低于 179 秒、解说镜头是否完整覆盖、镜头是否有空隙/重叠/越界/闪切/复用，以及同步 SRT 的顺序、重叠和音频尾差。弹窗用绿色对号、蓝色说明、黄色提醒和红色叉号区分结果；必须处理的问题会阻止正式预览，提醒项由用户判断，不调用 API。
- 多句文案使用同一个合适镜头属于正常情况：非相邻的完全相同区间只显示蓝色说明，通常无需处理；只有相邻镜头从头重复播放同一区间才显示黄色观感提醒，先看预览，确有明显跳回感时再到高级调整手动替换。
- FFmpeg 合成完成后会再用 ffprobe 实测输出文件，核对真实时长、分辨率、H.264/像素格式和音频轨道；不能再把“FFmpeg 返回成功”直接等同于成片完整。
- 没有可用 TTS 环境时，可直接使用程序估算生成的参考 SRT 创建“仅字幕测试预览”；该视频无声音，用于检查字幕节奏、样式和镜头衔接。
- “保留原片声音”默认关闭；开启后，仅字幕测试会保留所选镜头的原声，正式配音预览则以较低音量把原声混入英文解说。
- 默认最终视频完全移除原片声音，只保留英文配音。
- 原视频被移动后，预览前会先按文件名和文件大小在项目附近自动重新定位；找不到时弹出重新选择窗口，并校验时长和分辨率后更新项目路径，不会要求重新分析。
- 默认保持原视频分辨率和宽高比，不缩放、不补边、不裁切。
- 使用 ASS 烧录英文字幕。
- 提供黑色遮罩、局部模糊和 Delogo 三种字幕底板类型。
- 字幕底板同时遮住原字幕并承载英文字幕，不叠加第二层文字背景。
- 支持字体、字号、边距、文字/描边颜色、描边粗细、阴影、粗体、斜体、字间距及底板区域和效果强度调整。
- 内置标准字幕、清爽描边、Shorts 大字、纪录片暖白、科普黄字、极简白字六套预设；应用预设后仍可逐项微调并按项目保存。
- 字幕动画支持无动画、柔和淡入淡出和轻微弹出；动画写入最终 ASS，不增加 API 调用。
- 预览区支持方向锁定拖动、中心/边缘吸附、滑块和精确数值输入。
- 可按需调用 FFmpeg 生成真实字幕效果预览。
- 每次生成预览都会在根 `export/_internal/` 保存带项目文件名前缀的 FFmpeg 完整命令、错误输出和滤镜图，便于定位编码或滤镜问题。

## 安装

项目使用仓库根目录的共享虚拟环境：

```powershell
python -m venv venv
venv\Scripts\python.exe -m pip install -r requirements.txt
```

根目录 `requirements.txt` 已引用 StoryCut 的依赖清单，无需再重复安装子目录清单。

必须安装 FFmpeg 和 ffprobe，并加入系统 PATH；也可以在 `config.user.yaml` 中填写绝对路径。

## 启动

双击仓库根目录：

```text
点我启动StoryCut（AI解说剪辑）.vbs
```

该入口使用 `pythonw.exe`，启动和运行期间不会显示 CMD；依赖缺失时会直接弹窗说明。

也可以运行：

```powershell
venv\Scripts\python.exe storycut_v2/main.py
```

程序启动约 1 秒后会在后台静默检查更新；有新版时，首页按钮会显示绿色“● 可更新 v版本号”，不会自动弹出更新窗口。

## 配置与本地数据

- `config.default.yaml`：默认配置，提交到 Git。
- `config.user.yaml`：本机覆盖配置，不提交。
- `projects/`：用户项目、分析产物和缓存，不提交。
- `../export/`：用户可见的统一导出目录；当前存放 GPT-SoVITS SRT、仅字幕测试预览和成片预览，不提交。
- `../.env`：API 密钥和兼容接口地址，不提交。
- `../models/`：本地 Faster-Whisper 模型，不提交。

首页顶部提供“API 设置”入口，可直接查看当前配置状态并管理共享 `.env` 中的 `OPENAI_API_KEY` 和 `OPENAI_BASE_URL`。Key 默认遮盖显示；接口地址应填写 OpenAI 兼容 API 根地址（通常以 `/v1` 结尾），不要填写服务商网页或完整的 `/chat/completions` 请求地址。

API 设置还可分别配置故事生成模型、可选的最终故事编辑模型与视觉理解模型。纯画面模式适合让经济型模型完成批量视觉理解，让更强模型只承担全片故事编辑；最终编辑模型留空时自动复用故事生成模型。点击“选择模型”会异步读取中转站的 OpenAI 兼容 `/models` 接口，并在可搜索弹窗中列出模型；不支持列表接口时仍可手动输入模型名称。模型列表只代表接口可见，视觉理解模型仍需选择明确支持图片输入的型号。所选模型保存在 `config.user.yaml`，不会覆盖其他本机配置。

首次使用而本地没有语音模型时，StoryCut 会联网下载配置的模型。可在本机 `config.user.yaml` 中关闭：

```yaml
analysis:
  auto_download_model: false
```

关闭后缺少模型会直接给出明确错误，不会联网下载。

每个 StoryCut 项目包含内部工作数据：

```text
analysis/    转写、场景、关键帧和事件
script/      故事稿及 GPT-SoVITS 参考 SRT
timeline/    镜头匹配和粗剪时间线
audio/       英文配音、同步字幕及可恢复的原始导入备份
cache/       封面及预览缓存
project.json 项目状态与字幕设置
```

用户需要查找的文件统一位于仓库根目录 `export/`，并使用项目名作为文件名前缀，避免不同项目互相覆盖。

## 初版边界

- GPT-SoVITS 暂不内嵌，继续采用导出参考 SRT、外部生成、再导入配音和同步 SRT 的流程。
- Delogo 是基于周边像素插值的传统 FFmpeg 修复，复杂动态背景下可能出现拉伸纹理。
- 当前以单项目人工确认流程为主，尚未支持批量任务。
- 四个步骤支持独立收起/展开；长页面针对鼠标滚轮和触控板提高滚动距离。
- 竖屏画布、自动裁切和主体跟踪不属于默认行为，留待后续作为可选功能。

## 验证状态

初版已使用真实短视频完成全流程验证，包括原片分析、故事生成、镜头匹配、GPT-SoVITS 音频与 SRT 导入、字幕样式设置、真实效果预览和最终视频导出。
